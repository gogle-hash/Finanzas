# JavierSL - Capital Multi-Moneda (PWA)

App de gestión de capital, operaciones y gastos en varias monedas. Se instala en el teléfono y funciona sin internet.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio (los archivos en la raíz).
2. En *Settings > Pages*, elige la rama `main` y la carpeta `/ (root)`.
3. Abre la URL `https://TU-USUARIO.github.io/TU-REPO/` (debe ser HTTPS).

## Instalar
- **Android (Chrome):** menú ⋮ > *Instalar aplicación*.
- **iPhone (Safari):** botón Compartir > *Añadir a pantalla de inicio*.

## Actualizar la app
Cambia `VERSION` en `sw.js` (por ejemplo de `v1` a `v2`) al subir cambios. La app se actualiza sola la próxima vez que se abra con internet.
